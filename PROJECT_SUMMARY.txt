CÓMO COMENZAR
================================================================================

1. INSTALAR DEPENDENCIAS (ya hecho):
   npm install

2. INICIAR SERVIDOR DE DESARROLLO:
   npm run dev
   
   Abre: http://localhost:3000

3. EXPLORAR EL CÓDIGO:
   - app/                    - Código principal
   - app/components/         - Componentes reutilizables
   - app/pages/             - Páginas (layout.tsx, page.tsx)
   - app/config/            - Configuración centralizada

4. PERSONALIZAR:
   - Edita app/config/site.ts para cambiar datos
   - Edita app/globals.css para cambiar colores
   - Reemplaza contenido en pages
   - Agrega imágenes en public/

5. HACER BUILD:
   npm run build

6. DEPLOYAR:
   npm i -g vercel
   vercel
